Demonstration web folder

Seventeen example metadata files, one or more per format, for trying a harvester on. A harvester reads the links on this page. See README.md in this folder of the repository.

  • cdif-exampleCdifAccess.json CDIF JSON-LD: an access-conditions fragment, not a whole record. Expected to fail its check.
  • cdif-exampleDDEDataset.json CDIF JSON-LD: a Deep-time Digital Earth dataset record.
